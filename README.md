# 제주 가족여행 플래너

2026년 10월 26일~30일 가족 여행. 기존 1~5일차 일정과 개인 저장을 유지합니다.

## 가족 공동 편집

- 개인에게 전달된 가족용 링크로 연결한 뒤 ‘가족에게 공유’에서 링크를 복사하거나 공유합니다.
- 링크를 가진 사람은 같은 일정의 추가·수정·삭제·완료 체크가 가능합니다. 초대 키는 소스에 포함하지 않습니다.
- 화면이 열려 있으면 약 8초마다 변경을 확인하고, 다시 접속하거나 온라인으로 돌아오면 동기화합니다.
- 연결이 끊기면 브라우저에 수정 초안을 보관합니다. 저장 완료 전에는 브라우저 데이터를 지우지 마세요.
- 서로 다른 항목/필드의 수정은 3-way merge로 합칩니다. 같은 필드, 수정/삭제 충돌은 사용자가 선택합니다.
- 저장 API의 version 조건부 갱신으로 마지막 저장이 앞선 수정을 덮어쓰는 것을 방지합니다.
- ‘이 기기의 이전 수정 가져오기’로 기존 개인 수정과 공동 일정을 합칠 수 있습니다. 원본 개인 저장은 보존합니다.

## 운영

GitHub Pages는 main 브랜치의 루트에서 배포합니다. Safari → 공유 → 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

Supabase `family-trip` Edge Function은 256비트 초대 키의 SHA-256 해시를 확인한 뒤 서버에서만 데이터에 접근합니다. 테이블은 RLS가 켜져 있으며 공개 클라이언트 접근 정책이 없는 것이 의도된 설정입니다. 서비스 키는 서버 환경 변수에서만 사용합니다.

서버 소스: `backend/family-trip.js`. 프런트엔드 연결 주소: `app.js`. 공유키와 실제 공유 일정은 저장소에 넣지 않습니다. `access_hash`의 기존 초대 링크는 보존하고, 승인된 추가 링크는 `additional_access_hash`로 연결할 수 있습니다. 새 링크 권한 부여는 소유자 확인 후 진행합니다.

검증: `node --test tests/sync.test.cjs`. 실제 API 검증은 별도 테스트 일정으로 진행합니다.

3~5일차는 추천 일정이며 귀가 항공편 시각은 미정입니다.
